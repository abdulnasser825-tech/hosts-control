# التحكم بهوستات Spyro TV من GitHub

تعدّل ملفاً واحداً (`hosts.conf`) فيوقّعه GitHub (HMAC-SHA256) وينشره على GitHub Pages، والتطبيق يجلبه عند كل تشغيل أو دخول. الشكل والتوقيع مطابقان لإضافة ووردبريس، فلا تعديل في منطق الجلب.

## الإعداد (مرة واحدة)
1. أنشئ مستودعاً جديداً وارفع محتويات هذا المجلد كما هي (مع `.github`).
2. املأ `server1` و`server2` و`server3` في `hosts.conf`، ثم احفظ.
3. **Settings ← Pages ← Source: GitHub Actions.**
4. **Settings ← Secrets and variables ← Actions ← New repository secret**: الاسم `HOSTS_SECRET`، والقيمة مفتاح عشوائي طويل (32 حرفاً فأكثر، بلا مسافات). يجب أن يكون **نفس** `HOSTS_SECRET` المضمَّن في التطبيق؛ إن أردت إبقاء نسخ قديمة تعمل فاستعمل مفتاح الإضافة الحالي نفسه.
5. تبويب **Actions** ← `publish-hosts` ← **Run workflow**. بعد نجاحه افتح `https://<حسابك>.github.io/<المستودع>/hosts.json` وتأكد أنه يظهر.
6. في مستودع التطبيق ضع السر `HOSTS_URL` = الرابط أعلاه (وكذلك `HOSTS_SECRET`)، وأعد بناء التطبيق **مرة واحدة**.

> النسخ القديمة من التطبيق ما زالت تقرأ من ووردبريس (الرابط مثبّت داخل الـ APK). أبقِ الإضافة تعمل حتى يحدّث الجميع.

## الاستعمال اليومي (من تطبيق GitHub على الجوال)
افتح `hosts.conf` ← أيقونة القلم ← عدّل ← **Commit changes** (على `main`).

| الهدف | التعديل |
|---|---|
| إيقاف كل السيرفرات | `global = off` (ورسالة اختيارية في `global_message`) |
| تشغيلها | `global = on` |
| إيقاف سيرفر واحد | `server2_on = off` |
| تغيير هوست | بدّل عنوان `serverN` (الحسابات المحفوظة تتبع الرقم تلقائياً) |
| حذف هوست | امسح عنوانه |
| إعلان / فرض تحديث / واتساب | الأقسام الخاصة في الملف نفسه |

## أزرار التحكم (بدون تعديل الملف)
من تطبيق GitHub: **Actions ← control ← Run workflow**، ثم اختر:

| الإجراء | الأثر | خانة «القيمة» |
|---|---|---|
| `global_off` / `global_on` | إيقاف شامل / إلغاؤه | رسالة الإيقاف (اختياري) |
| `server_off` / `server_on` | إيقاف / تشغيل السيرفر المختار | رسالة الإيقاف (اختياري) |
| `set_host` | تغيير عنوان السيرفر المختار وتشغيله | العنوان الجديد (إلزامي) |
| `clear_host` | مسح عنوان السيرفر المختار | — |

يعدّل الزر `hosts.conf` ويحفظه باسمك في السجل (`control: … (by حسابك)`) ثم يشغّل النشر. يمر التعديل على نفس الفحص أولاً، فإن كان غير صالح يفشل التشغيل ولا يتغير شيء. ترك «القيمة» فارغة يُبقي الرسالة الحالية. إن فعّلت حماية الفرع `main` بحيث تمنع الدفع المباشر فسيفشل الزر؛ استعمل تعديل الملف عبر Pull Request.

## الفحص الدوري والتنبيه
كل 30 دقيقة يفحص `monitor-hosts` وصول الهوستات **المفعَّلة** فقط (طلب إلى `player_api.php` بلا بيانات دخول، ثلاث محاولات). إن لم يستجب أحدها يفتح Issue عنوانه «🔴 هوست لا يستجيب: سيرفر N» (بلا عناوين) فيصلك إشعار، وإن تغيّرت المجموعة يضيف تعليقاً، وعند العودة يغلقه. **لا يوقف شيئاً تلقائياً**؛ القرار لك عبر `control`.
- لتصلك الإشعارات: تطبيق GitHub ← الإعدادات ← الإشعارات، وفعّل Watch للمستودع.
- بعض المزوّدين يحجبون عناوين GitHub: إن ظهر تنبيه كاذب فاجعل `serverN_monitor = off` لذلك السيرفر.
- في المستودع العام يوقف GitHub الجداول الزمنية بعد 60 يوماً بلا نشاط؛ أي تعديل أو تشغيل يدوي يعيدها.
- يفحص الوصول فقط، فلا يكشف انتهاء اشتراكك عند المزوّد ولا بطء البث.

## ما يفحصه السكربت قبل النشر
مفتاح خاطئ الإملاء، قيمة on/off غير صحيحة، عنوان فيه مسافة أو منفذ خاطئ أو اسم مستخدم/كلمة سر، روابط غير https، تاريخ بصيغة خاطئة، و`min_version` أعلى من `app_version_code` (كان سيحجب كل المستخدمين). عند أي خطأ يفشل التشغيل **ولا يُنشر شيء** ويبقى آخر ملف سليم منشوراً؛ السبب بالعربية في سجل التشغيل.

## قيود يجب أن تعرفها
- **غير لحظي:** النشر نحو دقيقة، وGitHub Pages يخزّن الملف مؤقتاً (عادةً حتى 10 دقائق)، ثم يصل الجهاز عند تشغيل التطبيق أو الدخول.
- **الإيقاف لا يقطع الجلسات المفتوحة:** يُفحص عند الدخول فقط.
- **الخانات 3 بالضبط** (حد التطبيق). «الإضافة» = تعبئة خانة فارغة.
- **الملف علني:** `hosts.json` يُقرأ من أي أحد (كما في ووردبريس). مستودع عام يكشف أيضاً السجل القديم للهوستات؛ المستودع الخاص يخفيه لكن Pages للخاص يحتاج خطة مدفوعة.

## الأمان
من يملك صلاحية الكتابة على المستودع يتحكم بوجهة حسابات المستخدمين. فعّل التحقق بخطوتين، ولا تضف متعاونين لا تثق بهم، ولا تضع كلمات سر في الملف. المفتاح مضمَّن في الـ APK ويمكن استخراجه، فالتوقيع يحمي من التعديل الخارجي لا من اختراق حسابك.

## تطوير
`python3 -m unittest discover -s scripts` للاختبارات، و`python3 scripts/build_hosts.py --check` لفحص الملف محلياً.
